# Part 5 · Metrics beyond accuracy

Open `Part5_Metrics.ipynb`.

It compares the model with a `DummyClassifier` baseline, then the confusion matrix (with a chart), precision, recall, F1, ROC-AUC, and a threshold table. `churn_pipeline.py` and `customers.py` are shared modules. The notebook draws one chart, so it needs `matplotlib` from `requirements.txt`.
